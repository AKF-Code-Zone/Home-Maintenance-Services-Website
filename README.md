**Full Stack Web Application**

->HomeFix is a React.js application designed to help users easily find and book home maintenance services such as plumbing, electrical repair, and cleaning.

->It features a clean and professional design, smooth navigation using React Router, and modular component-based architecture. 

Each section (Home, About, Services, Contact, Login, Registration, Dashboard) is built for clarity and responsiveness. 

Its Frontend also converted in Next.js and Deploy on Vercel https://frontend-next-js-65c2-79pkunsc4-alishbakashafs-projects.vercel.app/

**Features**

**Dynamic Navigation :** Built using React Router for seamless multi-page navigation without reloads.

**Modern UI Design :** Fully responsive, minimalistic, and user-centric design using custom. CSS.

**Component Reusability :** Modularized components (Navbar, Footer, Cards) to ensure.maintainability.

**Instant Communication:** ReadyPlaceholder for integrating real-time chat or booking APIs.

**Authentication Pages :** Dedicated login and registration pages designed for easy backend integration.

**Mobile-Friendly Layout :** All pages are fully optimized for phones and tablets.

**Dashboard Ready:** Pre-structured dashboard for future user data and analytics display.

**Tech Stack:**

**Frontend:** React + Vite, Tailwind CSS / CSS (if used)

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Authentication:** JWT (JSON Web Tokens)

**State Management:** Context API 

**Others:** Axios for API calls, bcrypt for password hashing

**IDE Used:** Visual Studio Code

**Version Control:** Git & GitHub

**Installation & Setup**

1️⃣ Clone the Repository https://github.com/AKF-Code-Zone/Home-Maintenance-Services-Website 

2️⃣ Install Dependencies npm install

3️⃣ Run the Application ->If using Vite: npm run dev ->If using Create React App: npm start

4️⃣ Open in Browser -> Visit: http://localhost:3000

**Usage Instructions:**

Launch the app using npm run dev.
Navigate between pages using the top Navbar.
Explore available services on the Services Page.
Contact the team via the Contact Page form.
Register and log in to test form flows.
Optionally, extend Dashboard.jsx to show user-specific data.
